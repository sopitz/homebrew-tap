# sopitz/homebrew-tap

[Homebrew](https://brew.sh) casks for apps by sopitz.

## MirrorAct

Mirror, frame and record your iPhone, iPad or Android phone on your Mac –
[mirroract.com](https://mirroract.com), source code in [sopitz/MirrorAct](https://github.com/sopitz/MirrorAct).

```bash
brew install --cask sopitz/tap/mirroract
```

Update with `brew upgrade --cask mirroract`, remove with `brew uninstall --cask mirroract`
(`--zap` also removes settings and logs). Needs macOS 15 or later on Apple silicon.

The cask is updated by `scripts/release.sh --publish` in the MirrorAct repository.
